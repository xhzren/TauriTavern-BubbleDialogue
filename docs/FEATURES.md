# 功能说明

> ⚠️ 本文件已按当前实现重写。原模板的 4 个示例模块说明已删除。
> 完整的交接信息（名词表、数据契约、铁律、待定事项）见仓库根目录 `HANDOFF.md`。

本扩展把两个 JS-Slash-Runner 脚本合并为一个 TauriTavern 原生扩展，提供 4 个管理页面。

---

## 头像管理 (`src/features/bubble-render/components/AvatarsPage.vue`)

- 左栏：库范围切换（全局 / 按角色卡）、上传（点击或拖拽）、搜索、头像列表
- 右栏：选中头像的**情绪差分**列表 + **CG 图库**，点缩略图在大图区预览
- 支持删除头像（连带其全部情绪差分）

**注意**：没有打开角色卡时（ST 返回 `SillyTavern System`）范围强制为全局，按角色卡按钮置灰。

---

## 正文美化 (`StylePage.vue`)

16 个滑杆（台词/旁白字号、行距、字重、头像大小、旁白留白与圆角、心里话尾符等）+ 颜色 + 字体 + Markdown 开关。

> ⚠️ **当前只写入配置，没有任何代码消费它们** —— 原脚本把它生成 CSS 注入页面的那段没有移植。
> 详见 `HANDOFF.md` §8.1。

---

## 情绪配置 (`MoodPage.vue`)

- **格式规则**：注入给模型的 `@bubble` 输出规范，可编辑、可恢复默认
- **情绪词配置**：8 组情绪词的增删与配色

数据存 `config` 表的 `format_rule` / `mood_config` / `mood_prompt_template`。

---

## 存储 (`StoragePage.vue`)

顶部双面板切换：

### 原版 DB 面板
列出原版 IndexedDB 中各范围的占用（全局 + 每张角色卡），每行带 `转换` / `删除`，
标题行带 `一键转换并删除`。转换是**复制到原生存储、不删源**；删除不可撤销。

### TT 原生面板
导入 ZIP / 导出 ZIP / 统计数据 / 运行状态。

**默认后端固定为 TT 原生**，没有切换器 —— 数据迁移走原版 DB 面板的转换按钮。

---

## 运行链路（不占页面）

| 文件 | 职责 |
|---|---|
| `prompt-injector.ts` | 把格式规则 + 情绪词约束注入 outgoing prompt |
| `bubble-hydrator.ts` | 扫描 `.yq-bubble`，填头像、上情绪色、分对白/心里话 |
| `avatar-resolver.ts` | 6 级回退链解析头像 URL + blob 缓存 |
| `runtime.ts` | 共享运行时：存储、事件订阅、统计、引用计数生命周期 |
